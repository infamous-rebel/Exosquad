Single-file library (`src/index.ts`) re-exported as `@exosquad/common` (see `package.json`). Internal structure is flat and organized into three logical sections: (1) an error hierarchy rooted at `AppError` with typed subclasses (`NotFoundError`, `UnauthorizedError`, `ForbiddenError`, `ConflictError`, `ValidationError`, `RateLimitError`, `SourceError`) each carrying a stable HTTP `statusCode`, string `code`, and optional `context`; (2) shared Zod schemas (`paginationSchema`, `sortSchema`, `idParamSchema`) whose inferred types are re-exported as `PaginationParams`, `SortParams`; (3) plain TS interfaces (`PaginatedResult<T>`, `AuthenticatedRequest`, `HealthStatus`) used uniformly across services. The package has no runtime dependencies beyond `zod` and is marked `private` so it is only consumed internally by sibling packages via the workspace.
