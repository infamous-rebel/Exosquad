The workspace root is a pnpm workspaces project (`packages/*` + `apps/*`) orchestrated by Turbo v2. `package.json` exposes top-level scripts (`build`, `dev`, `test`, `lint`, `typecheck`) that delegate to `turbo run`, with `turbo.json` declaring task dependencies so library builds (`^build`) precede app tasks. The runtime splits into two Node processes: `apps_api` (Fastify HTTP server) and `apps_worker` (BullMQ consumer), both consuming shared libraries under `packages/` — `@exosquad/common` for Zod schemas/types/errors, `@exosquad/config` for typed env validation, `@exosquad/database` for Prisma client/migrations, `@exosquad/logger` for Pino child-loggers, and `@exosquad/connector` for external data fetching. Local infrastructure is provided by `docker-compose.yml` spinning PostgreSQL 16 and Redis 7, which the API and worker connect to via the shared config. Vitest is configured at the workspace level (`vitest.workspace.ts`) so tests across all packages/apps are discovered uniformly.
