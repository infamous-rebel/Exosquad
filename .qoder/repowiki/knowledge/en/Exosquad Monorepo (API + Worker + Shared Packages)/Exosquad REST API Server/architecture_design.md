The module is a Fastify application bootstrapped by `src/index.ts`, which instantiates the `App` class in `src/app.ts`. `App` wires together four layers: (1) plugins under `src/plugins/` (`request-tracker`, `auth`, `rate-limit`, `security-headers`) registered via `server.register`; (2) route modules under `src/routes/` mounted with prefixes (`/health`, `/api/v1/auth`); (3) business logic under `src/services/` (currently `AuthService` handling signup/login/profile against Prisma via `@exosquad/database`); (4) a global error handler that normalizes `AppError` subclasses and Zod validation failures into a uniform `{error:{code,message}}` JSON envelope. Cross-cutting concerns are encapsulated as Fastify plugins using `fastify-plugin` so decorators like `authenticate` and `user` leak to child scopes. The process entry point registers SIGTERM/SIGINT handlers for graceful shutdown. Tests are split into unit tests (`test/unit/`) and integration tests (`test/integration/`) driven by two Vitest configs; integration tests use a separate config with a 60s timeout.
