Single-package library (`@exosquad/connector`) exposing one public entry point `src/index.ts` that re-exports everything from `http-connector.ts`. Internal modules are organized by cross-cutting concern: `auth.ts` (none/api_key/bearer/basic/oauth2 strategies), `pagination.ts` (page/offset/cursor/link strategies), `retry.ts` (exponential backoff + jitter via `withRetry`), `rate-limiter.ts` (token-bucket per source), `circuit-breaker.ts` (per-source state machine), `content-hash.ts` (SHA-256 body hashing for deduplication), `field-mapping.ts` (response record transformation), and `errors.ts` (typed error hierarchy rooted at `ConnectorError extends AppError`). `types.ts` defines the shared contracts (`SourceConfig`, `FetchResult`, `PaginatedFetchResult`, `CheckpointState`) plus utilities (`sanitizeRequestHeaders`, `validateOutboundUrl`, `buildUrl`, `extractResponseDataArray`). `HttpConnector` composes these concerns in a fixed pipeline inside `fetch()` / `fetchAll()`: circuit breaker → rate limiter → retry wrapper → request build → SSRF validation → HTTP call → response parse → content hash. Dependency direction is strictly inward: `http-connector.ts` imports all other modules; sibling modules do not import each other except through `types.ts`; nothing here imports the rest of the repo beyond `@exosquad/common` and `@exosquad/logger`.
