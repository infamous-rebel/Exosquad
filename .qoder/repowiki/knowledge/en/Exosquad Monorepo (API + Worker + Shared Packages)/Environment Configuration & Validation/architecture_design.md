Single-file module (`src/index.ts`) built with TypeScript and published as `@exosquad/config`. It declares one Zod schema (`envSchema`) grouping env vars by concern (Database, Redis, Application, Authentication, Worker), then exports three symbols: the inferred `Env` type, a `loadEnv()` function that calls `safeParse(process.env)` and throws on failure, and a top-level `config` singleton created at import time. The package is private (`private: true` in `package.json`) so it is only consumed internally; build output goes to `dist/` via plain `tsc`.
