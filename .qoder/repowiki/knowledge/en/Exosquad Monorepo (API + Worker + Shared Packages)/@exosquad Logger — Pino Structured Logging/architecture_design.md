Single-file module (`src/index.ts`) that instantiates a Pino logger configured via environment: `LOG_LEVEL` controls severity, `NODE_ENV !== 'production'` switches the transport to `pino-pretty` (colorized, human-readable) while production emits newline-delimited JSON for log aggregation. A shared root `logger` is exported as both named and default export; `createChildLogger(bindings)` wraps `logger.child()` so callers can attach per-request bindings such as `requestId`, `tenantId`. The package is private (`"private": true`), published only as TypeScript sources compiled by `tsc` into `dist/`, consumed by other workspace packages through the `@exosquad/logger` name.
